# MetroSim 地铁站客流仿真系统 - 答辩演示文档

---

## 一、项目背景与意义

### 1.1 研究背景

随着城市轨道交通的快速发展，地铁站客流管理面临日益严峻的挑战：
- 高峰时段客流拥堵严重
- 突发事件应急预案缺乏数据支撑
- 站厅设计优化需要量化依据

### 1.2 项目目标

开发一套**地铁站客流微观仿真系统**，实现：
- ✅ 站厅拓扑的可视化建模
- ✅ 乘客行为的真实模拟
- ✅ 智能路径规划与决策支持
- ✅ 多维数据的可视化分析

### 1.3 技术创新点

| 创新点 | 描述 |
|--------|------|
| 多目标路径规划 | 支持5种寻路策略 + Pareto前沿方案对比 |
| 状态机驱动仿真 | 精确模拟乘客进站全流程行为 |
| 实时可视化监控 | 2D/3D视图联动，直观展示客流状态 |
| 开放配置接口 | JSON格式站点定义，易于扩展新场景 |

## 四、关键技术实现

### 4.1 仿真引擎核心逻辑

**时间步进流程**（simulation.cpp）：

```cpp
void Simulation::step() {
    // 1. 根据客流率生成新乘客
    generatePassengers();
    
    // 2. 更新每位乘客状态
    for (auto& passenger : passengers_) {
        updatePassenger(passenger);
    }
    
    // 3. 清理已完成乘客
    removeFinishedPassengers();
    
    // 4. 记录统计数据
    updateStatistics();
    
    // 5. 触发UI更新
    emit simulationUpdated();
}
```

### 4.2 A* 路径规划

**启发函数设计**（path_planner.cpp）：

```cpp
double heuristic(const Node& from, const Node& to, PathObjective objective) {
    switch (objective) {
        case PathObjective::MinTime:
            return distance / averageSpeed;
        case PathObjective::MinDistance:
            return distance;
        case PathObjective::MinCongestion:
            return currentOccupancy / capacity;
        // ...
    }
}
```

## 五、实验结果

### 5.1 仿真指标

| 指标 | 说明 | 计算方式 |
|------|------|----------|
| 平均通行时间 | 乘客从进入到出站的平均时长 | 总通行时间 / 完成人数 |
| 完成率 | 成功出站乘客比例 | 完成人数 / 总进站人数 |
| 拥堵率 | 发生拥堵的节点占比 | 拥堵节点数 / 总节点数 |
| 队列长度 | 各节点排队人数 | 实时统计 |

### 5.2 对比实验

**不同路径策略对比**：

| 策略 | 平均时间(s) | 平均距离(m) | 拥堵次数 |
|------|-------------|-------------|----------|
| MinTime | 85 | 120 | 45 |
| MinDistance | 95 | 95 | 38 |
| MinCongestion | 90 | 110 | 22 |
| WeightedSum | 87 | 108 | 30 |

### 6.1 技术亮点
